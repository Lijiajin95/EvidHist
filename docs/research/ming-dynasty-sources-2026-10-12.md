# 明代公开资料下载入口与采集交接

日期：2026-10-12（Asia/Shanghai）。本文保存本次会话的明代选源建议，供后续采集 Agent 使用。原创说明采用项目 [CC BY-NC-SA 4.0](../../LICENSE-DOCS.md)；第三方史料和数据保留各自许可。

**当前状态：只完成来源调查与文档整理，未实际下载史料、逐卷核验完整性或导入数据库。** 下列入口和条款信息不等于具体材料已经通过本项目的使用许可核查，也不保证零法律风险。

用户已将第一版研究朝代定为明代。现有[最小启动需求](../mvp-scope-and-backlog-2026-10-12.md)以“于谦—北京保卫战”为试点，首版只服务用户本人，以一小组真实材料完成首个研究任务；具体问题和实际材料尚待确定。本文的全朝书目是候选来源，不增加全文量、书目数量或批量采集的首版门槛。此前会话提出的“土木堡之变”仅是起步建议，可作为试点背景，不替换已确认需求。

### 1.1 少量资料下载

进入作品或分卷页面，在“工具／打印与导出”中选择 EPUB、PDF 等格式。导出后检查实际包含的卷次和正文，避免把目录页导出误记为整部书下载。

首版需要可用文本；只有 PDF 图像而没有可核对文本时，先记录材料和缺口，不把 OCR 系统建设加入本次资料准备。已有工作台支持文本粘贴和 `.txt` 导入，见 [v0.1 交付说明](../v0.1-delivery.md)。

### 1.2 整站文本下载

- [官方整站下载目录](https://dumps.wikimedia.org/zhwikisource/latest/)
- [中文维基文库下载说明](https://zh.wikisource.org/wiki/Help:下载维基文库)
- 可选文件：`zhwikisource-latest-pages-articles.xml.bz2`，为压缩 XML，内容含维基标记，并非整理好的纯文本或仅明代资料。
- 本次调查所见 2026-10-02 批次约为 9.6 GB（压缩文件）；后续批次的大小和内容可能变化。

小专题优先按作品和卷次获取。确需整站包时，记录实际批次、下载地址和内容散列，筛选相关页面，并保存页面 ID／修订 ID。不要只保留会变化的 `latest` 链接。

### 1.3 许可与文本质量

[《明史》页面](https://zh.wikisource.org/wiki/明史)将古代原文标为公有领域，并另行说明后加标点的权利状态；站点文字采用 CC BY-SA 4.0，附加条款可能适用。原文、后加标点、注释、校对贡献和扫描件应分别核查，不能把整个网页统一登记为“无版权”。

遵循[史料来源与许可指南](../source-licensing-guidance.md)：第三方 BY-SA 内容不能直接改以本项目的 BY-NC-SA 文档许可发布；页面转录不自动意味着经过可靠校对。采集副本保留原字形及原记年，简繁转换、异体字归一化、自动标点或 OCR 修正放在处理副本中，并说明修改。

## 2. 扫描件来源

### 2.1 日本国立公文书馆

- [《明史》馆藏条目](https://www.digital.archives.go.jp/file/en/3610285)：可作为旧版本扫描件的检索起点。
- [数字档案入口](https://www.digital.archives.go.jp/)
- [官方使用说明](https://www.digital.archives.go.jp/support/)
- [数据二次利用规则](https://www.digital.archives.go.jp/secondary-use)

官方说明：有数字内容的材料可在浏览器中查看、打印和下载；数字内容可用于商业及非商业用途，可复制、修改和再分发，目录元数据采用 CC0。仍需遵守其他适用权利及法规，并保留出处；网页说明文字的许可不与目录、馆藏内容混为一谈。

操作建议：搜索具体书名，查看条目下的分册和数字内容入口，再通过阅读器的下载功能保存所需扫描件。登记馆藏机构、条目 URI、参考编号、版本、册次及图像页序，注意图像页序与原书页码可能不同。

**核验限制**：本次会话读取了官方搜索索引提供的条目、下载说明和二次利用规则摘要；直接读取部分页面失败，规则页返回 403。尚未通过浏览器完成具体分册下载或留存完整条款快照。后续采集 Agent 应正常打开官网核对，不绕过访问限制。

### 2.2 哈佛燕京图书馆 Chinese Rare Books

- [中文善本数字馆藏](https://curiosity.lib.harvard.edu/chinese-rare-books)
- [哈佛中文馆藏介绍](https://library.harvard.edu/collections/chinese-collection)
- [哈佛图书馆版权政策](https://library.harvard.edu/about/policies/harvard-library-cc-copyright-policy)

适合补地方志、家谱、明清人物文集及旧版本古籍。先搜索具体书名、作者或地区，进入单书数字阅读器，检查该条目的数字访问和下载选项；不要假设整个馆藏都有统一的全文导出接口。

哈佛官网明确指出，网页上的 CC BY 标识不自动覆盖馆藏书籍和扫描图片。对选中的条目分别确认材料权利状态、允许用途和取得方式，保存条目及许可信息。

**核验限制**：已读取官方馆藏介绍和版权政策；善本门户直接读取失败，尚未实测单书下载或逐件确认许可。该来源当前为补充候选，不登记为已获授权的资料。

## 3. 人物数据：CBDB

- [官方单机版下载入口](https://cbdb.hsites.harvard.edu/download-cbdb-standalone-database)
- [API 文档及授权说明](https://input.cbdb.fas.harvard.edu/cbdbapi/index.html)

单机版提供 Access 和 SQLite 下载入口，可筛选明代人物，辅助整理姓名、籍贯、任官、亲属和社会关系。它是现代整理的结构化数据，不替代原始史料，也不能单凭实体关系确认历史论断。

单机版学术数据采用 CC BY-NC-SA 4.0。API 条款自 2026-08-20 起按当前单机版发布日期及数据量分界：此前且在范围内的数据仍适用 CC BY-NC-SA 4.0；较新或超范围数据适用自订条款，禁止商业使用、演绎、再分发及向第三方提供访问，包括作为公开网站、应用或 API 的数据来源。未明确许可的用途须取得书面授权，以完整条款为准。

首版私人研究仍需核对实际用途；后续公开查询或商业化时重新核查授权。采集时锁定所用发布版本和其条款，不混入授权范围不同的 API 数据。

**核验状态**：本次会话已读取官方单机版下载页和 API 授权摘要；未下载数据库、检查具体人物覆盖或确认本项目逐用途许可。CBDB 只作为可选辅助数据，不增加首批资料准备门槛。

## 4. 首批资料建议

按已有“于谦—北京保卫战”试点，围绕具体问题准备少量材料：

1. 《明史》中相关人物列传、事件及本纪记载。
2. 《明英宗实录》中对应时期的相关卷次，从《明实录》目录进入。
3. 《明史纪事本末》中相关事件篇章。
4. 根据已发现的文本疑点或实际缺口，补对应旧版本扫描件；根据问题需要再补制度材料及 CBDB 数据。

该组合是资料准备建议，不代表已确定具体卷次、引文、历史结论或完整覆盖。收集的材料不足以支持结论时，保留缺口；三本书可能存在共同出处或转引关系，不能自动视为三份独立证据。

## 5. 给后续采集 Agent 的交接要求

后续工作先阅读本文、[最小启动需求](../mvp-scope-and-backlog-2026-10-12.md)、[史料来源与许可指南](../source-licensing-guidance.md)及 [AGENTS.md](../../AGENTS.md)。

### 5.1 最小步骤

1. 按首个具体研究问题列出所需作品、版本和卷次，明确本次资料保存目录与文件范围。
2. 核对选中材料的许可及用途，优先官方导出或下载。访问失败、限制不明或未获许可时记录原因及未知状态，不绕过登录、验证码、付费或封禁限制。
3. 保存实际取得的原始文本、导出文件或扫描件，以及来源、版本和许可记录；处理副本与原始材料保持区别。
4. 检查文件能否打开、是否仅有目录、是否缺卷或缺页、是否含乱码、转录是否校对；按实际检查范围登记，不因下载成功就标为全文完整。
5. 输出取得材料清单与未取得清单，注明实际文件位置、检查结果及仍待核查事项。资料准备与程序开发分别安排；首版不因此新增批量采集平台、OCR 系统或自动入库能力。

项目已将 `crawler/` 下的本地采集脚本及史料快照排除出 Git，见 [.gitignore](../../.gitignore)。如采用该目录，应明确实际文件位置；原始资料不默认随开源代码发布，是否再分发取决于具体许可。

### 5.2 每份材料至少记录

| 字段 | 要求 |
| --- | --- |
| 资料身份 | 书名、作者／编者、成书年代、所用版本、卷次／篇目；未知显式记录。 |
| 来源与取得时间 | 机构或站点、原始及实际下载地址、来源 ID、获取日期与时区。 |
| 可回查位置 | 页面 ID／修订 ID，或馆藏编号、册次、原书页码与图像页序；区分各类页码。 |
| 原始文件 | 实际保存位置、格式、内容散列；文本处理或 OCR 的方法及修改另行记录。 |
| 许可 | 适用许可证、条款链接及快照、核对日期；分别确认保存、解析、检索、公开展示、再分发和模型使用等实际用途。 |
| 完整性与校对 | 实际取得范围、缺卷／缺页／乱码、转录及校对状态、人工抽查位置；未检查项记为未知。 |
| 来源关系 | 已知转引、共同出处及版本关系；来源独立性不明时保留未知。 |

这些是本次资料准备的登记要求，不是新增数据库或 API 契约。
