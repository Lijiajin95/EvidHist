# 识典古籍专项研究：公开能力、证据边界与 EvidHist 重合关系

核验日期：**2026-10-10，Asia/Shanghai**。比较对象是 EvidHist [README](../../README.md) 的完整设计目标及当前 v0.1 工作台，二者分别判断。原创分析采用本项目 CC BY-NC-SA 4.0；所引用平台、文档、整理本、影像和数据仍适用各自条款。

## 1. 本次结论

**识典古籍与 EvidHist 的重合范围很大，已超出“免费古籍阅读网站”。** 官方资料覆盖史料整理、版本校勘、元数据、实体关系、阅读检索以及生成研究报告，并明确追溯引用的产品方向。因此不能将“中文史料 + AI 研究 + 可追溯引用”作为 EvidHist 已经独有的定位。[平台首页](https://www.shidianguji.com/zh/)、[北大整理平台介绍](https://gujiai.pkudh.net/ai-collation/index.html)、[字节官方 CSR 报告入口](https://gongyi.bytedance.com/report)

本次仍**未核实**它是否把下列行为实现为稳定、可导出、可验收的研究对象：同源转引不重复计作独立证据；真实冲突双方并列保存；每条论断分别记录“史料怎么说”与“历史事实是否核实”；未知、推断、争议及证据强度附判定依据；引用在文本更新后仍固定到旧版本。这些是待比较问题，不能写成识典“没有这些功能”。

免费访问也不能直接推出全部内容采用开放许可或可批量复用。官网《毛诗名物解》版权页明确记载《儒藏》编纂与研究中心授权平台发布，并保留版权；许可应按具体材料核查。[版权实例](https://www.shidianguji.com/book/RZ0393A/chapter/1lw9hwjbdk56a)

**本次没有成功完成浏览器交互，也没有实际使用深度研究助手。** 所以结论来自官方网页正文、官方搜索索引及项目本地目标对照，不能冒充模型表现或产品行为实测。

## 2. 研究方法与证据层级

只采用识典官网、北京大学数字人文中心及北大机构页面、字节跳动公益官方资料作为能力事实依据。检索包含整理平台、深度研究、引用链、版本关系、来源独立性、冲突、未知、置信、导出、API、开源和许可等中英文表达。第三方导览和转载用作寻找一手资料的线索，没有把其功能/协议转述当作已核实事实。

| 标记 | 含义 | 能说明什么 |
| --- | --- | --- |
| **正文** | 阅读到官方网页完整或相关正文 | 官方确实这样描述，不等于效果已经实测 |
| **索引** | 搜索返回官方页面/PDF的相关内容，正文访问失败或已经跳转 | 可保留为一手声明线索，但降低证据强度并记录失败 |
| **界面未完成** | 尝试打开或选择浏览器页超时 | 没有取得成功交互的证据；不能判定平台功能失效 |
| **待核** | 本次没有足够公开证据 | 保留未知，不据此断言不存在 |

本次直接读取可访问的书籍和版权网页，仅为观察条目结构及授权声明；没有下载、导入或批量采集史料，没有注册、登录或上传研究材料。未固定平台版本，也未保存全部网页/许可快照。

## 3. 平台性质与公开产品边界

官网将识典分为三部分：整理平台、APP、古籍阅读研究平台。整理面向加工与协作；APP含译文、听书、播客和 AI 问答；阅读研究平台含图文对照、字典百科、实体关系/地图及深度研究助手。这是当前官网产品描述，不能把某一部分的能力自动外推到另两部分。[首页](https://www.shidianguji.com/zh/)

北京大学数字人文研究中心记录双方共建数字人文开放实验室和平台；字节公益强调面向社会免费开放与资源共建。这支持将其归为**企业公益与高校合作的产品平台**，不宜仅凭免费或“开放实验室”称其开源。[北大中心介绍](https://pkudh.org/about.html)、[字节公益项目介绍](https://gongyi.bytedance.com/issue/7160869621275363364/7160869621275379748?page_from=header)

| 层级 | 当前有依据的描述 | 本次没有确认的边界 |
| --- | --- | --- |
| 阅读服务 | 免费面向公众的古籍检索、阅读及辅助工具 | 每项功能的账号/额度条件，是否始终匿名可用 |
| 整理工具 | 人机协作处理影像、文本与版本，含质量控制流程 | 实际上传、多人权限、编辑记录和导出结果 |

| 资料权利 | 可见具体出版整理本的授权发布和版权声明 | 全平台统一开放许可、商业使用、批量获取及再发布权利 |

## 4. 整理平台：已经有比“识别文字”更完整的流程

北大介绍把处理分成机器初处理与人工增强，流程包含 OCR、结构整理、文字精校、多版本校勘、标繁、标点、实体和译文校对；元数据既有书名/作者/版本/年代/分类，也涉及引用及版本关系，标准说明提到 TEI XML、CBETA-XML 和图文对照。[整理平台介绍](https://gujiai.pkudh.net/ai-collation/index.html)

“我是校书官”公开页进一步区分大众组的逐行 OCR 粗校与进阶组的精校、标点审核、结构和实体处理，列出二级审核及专家终审。这说明质量工作并非只依赖一次模型输出，也不能把所有上架文本视为同等精校程度。[项目与质量流程](https://gujiai.pkudh.net/i-am-a-proofreader/)

| 能力 | 已核实的一手描述 | 与 EvidHist 的关系 | 本次验证状态 |
| --- | --- | --- | --- |
| OCR 与版式处理 | 支持古籍特殊字形，处理影像与文字结构 | 史料采集与结构化重合；EvidHist 当前以已有可用文本为主 | 文档已读，未运行 OCR |
| 标点、分段和结构 | 机器初标后人工整理标题、段落等 | 文本可计算化与原文对应重合 | 未核实具体格式往返保持 |
| 多版本校勘 | 比较底本/校本与已有文本 | 与版本管理、异文识别明显重合 | 未验证一项真实校勘差异 |
| 实体与外部解释 | 人名、地名、书名、时间、官职等标签及人工校对 | 实体抽取和消歧前置任务重合 | 识别与消歧效果未实测 |
| 分层质量控制 | AI整理、粗校、精校与人工审核 | 来源文本质量元数据值得比较 | 不推断为统一评测结果 |
| 元数据与关系 | 版本、年代、分类、引用关系、版本关系 | 不能笼统宣称平台没有版本或引用结构 | 数据模型实际强制约束待核 |

OCR、标点和校对的准确率或速度在官方不同页面出现不同数字。本报告不把它们作为当前统一质量指标：本次没有取得一致的评测材料、模型版本、指标分母或独立复现实验。[概述页](https://gujiai.pkudh.net/ai-collation/overview/)

旧的第二期培训课索引说明整理本可动态由粗到精更新，强调研究者选择底本/校本，并涉及馆藏、影印信息、访问链接和许可元数据。该旧路径目前重定向到新站首页壳，详课只在官方搜索索引读取到，不能保证全部步骤仍是当前产品行为。[旧官方培训入口](https://gujiai.pkudh.org/academic-activities/proofreader/training-and-reviewing/courses-phasetwo/)

**解释边界：** 校勘比较的是文本记载与版本差异，不自动判断历史事实真假；精校可以改善字形和标点，不自动提高某位作者记载的史实可信度；“引用关系/版本关系”的元数据声明也不直接证明系统会识别共同出处、去除重复互证或计算证据独立性。

## 8. 与 EvidHist 的实际重合及差异

| EvidHist 目标或现状 | 识典公开资料对应 | 现实判断 |
| --- | --- | --- |
| 史料基础设施 | 资源、版本元信息、人机整理、检索与实体 | 已有强重合；从头建设通用古籍库和基础阅读会面对现成免费替代 |
| 中文文言文及近现代文本 | 大量汉籍与已确认的民国条目 | 语言/史料方向明显重合；近现代整体覆盖仍需逐库核查 |
| 不可变版本及引用位置 | 版本关系、图文对照、引用链描述 | 不能宣称对方无版本；稳定旧文本绑定与持久导出仍待比较 |
| 多来源对照 | 校勘、相似检索、跨材料研究 | 对照任务已有重合；对照不等于史事实互证已经完成 |
| 事实/推断/争议/未知 | 文本质量级别已有说明，论断状态规则未核实 | 可能形成明确验收差异，但目前还不是已证实的竞品缺口 |
| 来源独立性 | 元数据关联层已有引用和版本关系 | 重复引用去重、共同出处识别与证据权重待核，不能从文档空白推断没有 |
| 可追溯生成 | 研究报告与引用链方向直接重合 | 只做“AI回答带引用”难以构成清晰区别 |
| 图谱与时空 | 实体关系/地图及结构化数据方向 | 可视化本身已有重合，路径的证据与推断语义需实际检查 |
| 当前 v0.1交付 | EvidHist 已实现本地材料、不可变文本版本、引文校验、论断证据与 PostgreSQL 持久化 | 这些是本项目已实现行为；未证明整体研究效果优于识典，自动互证和完整图谱仍属设计目标 |

上表右列是依据公开事实和本项目目标作出的判断，不是识典的实测缺陷清单。EvidHist 能否提供额外价值，取决于用户真实任务和已完成行为，不能以尚未实现的规划对比对方已经可用的服务。
