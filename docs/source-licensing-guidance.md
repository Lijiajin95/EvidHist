# 史料来源与许可指南

本文用于 EvidHist 在**中国大陆境内建立历史资料库、并可能公开提供查询**时，选择史料来源、核查使用许可和登记材料权利信息。

内容为用户 2026-10-09 提供的来源与许可建议整理。本次会话抽查了所引链接的可达性，并对其中部分条款原文做了核对，明细见[第 7 节](#7-本次核验记录2026-10-09)。**本文不是法律意见**，也不对任何具体材料作出可用性结论；涉及授权范围争议时，以权利人书面答复或专业法律意见为准。

**当前状态**：选源原则与材料登记要求已经明确；采集器尚未实现，也尚未引入任何第三方材料。因此本文描述的是**引入材料前必须完成的工作**，不是已完成的合规审查结果。

## 1. 判断顺序

1. **优先选择权利状态清楚的来源**：公版史料、明确开放许可的数据、权利人书面授权的资料。
2. **“公开”“公益”“开源仓库”都不能单独保证零风险**。必须确认具体材料允许怎样获取、保存和使用。
3. **先选来源，再选获取方式**。来源与获取方式是两件事：下载、API、爬虫、人工整理都只是获取方式。先确认来源的权利状态，再决定用哪种方式取回。
4. **按用途分别确认**。下载阅读、内部分析、公开展示、再分发、模型训练是不同用途，需要分别得到许可；“仅供研究”通常不自动覆盖公开服务或全文发布。

## 2. 可选途径与降险方式

| 途径 | 能获取什么 | 怎样降低法律风险 |
| --- | --- | --- |
| **公版史料数字库** | 正史、实录、地方志、文集、旧报刊 | 逐部确认原文、版本和新增内容的权利状态。中文维基文库提供[整站文本下载](https://zh.wikisource.org/zh/Help:下载维基文库)，使用时仍需核对[版权信息](https://zh.wikisource.org/wiki/Wikisource:COPY)。 |
| **开放知识数据库** | 人物、年代、地点、机构及关系 | 例如 [Wikidata 的结构化数据采用 CC0](https://www.wikidata.org/wiki/Wikidata:Licensing)，适合实体对齐和检索；具体历史论断仍应回查史料。 |
| **博物馆、图书馆的开放接口** | 文物信息、历史照片、地图、手稿、扫描件 | 只使用明确授权的条目。例如 Smithsonian 提供 API 和批量数据，但要选[标为 CC0 的资源](https://www.si.edu/openaccess/faq)。 |
| **学术数据存档平台** | 历史人口、经济、气候、碑铭、标注语料等研究数据 | 从 Zenodo、大学数据仓库等下载原作者发布的数据，逐条核对许可。[Zenodo 的记录设有许可证字段](https://help.zenodo.org/docs/deposit/describe-records/licenses/)，平台上的数据并非统一授权。 |
| **书目、目录和版本元数据** | 作者、年代、版本、馆藏位置、文献标识 | 可以先建立“资料在哪里”的索引。例如 [Europeana 的元数据采用 CC0](https://www.europeana.eu/en/rights/usage-guidelines-for-metadata)；这个授权不自动覆盖对应的图片和全文。 |
| **政府公开文件、档案开放服务** | 历史法令、行政文件、公报、档案目录 | 中国《著作权法》第五条排除部分具有立法、行政、司法性质的官方文件；**政府网站上的其他文章、照片、研究报告仍需分别核对**。[法律依据](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html) |
| **权利人直接授权或机构合作** | 专题数据库、整理本、论文、档案数字副本 | 与作者、出版社、研究机构签订许可，明确批量获取、存储、OCR、检索、公开展示和再分发的范围。收费资料也可以通过这条途径合法使用。 |
| **自行数字化公版纸质材料** | 老版本古籍、旧地图、旧刊物 | 确认所用版本的财产权保护期已届满，并遵守馆藏拍摄规则；自行扫描、OCR、校对。现代注释、译文和整理成果可能另有版权。[法律依据](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html) |
| **自行采集、委托整理和社区贡献** | 口述史、碑刻记录、地方史材料、人工转录和标注 | 明确贡献者有权提供材料，并约定使用许可。口述史、近现代人物资料还涉及个人信息，公开的信息也不能无限制处理。[个人信息保护法](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_f374e8245320413181742e6d1baf4366.html) |

## 3. 需要额外注意的来源类型

- **GitHub：分别检查代码许可和数据许可。** 仓库公开不等于允许任意复制、分发；没有许可证时，默认版权规则仍适用。[GitHub 官方说明](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)
- **商业网站和公益网站：都应核对具体授权。** 遵守 robots.txt、控制请求频率只是采集规则，不能替代内容使用许可；架构文档已按 RFC 9309 记录“robots 并非访问授权”。经营场景下，不当获取数据、搬运后实质替代原平台服务，还可能涉及不正当竞争。[最高人民法院说明及指导案例](https://www.court.gov.cn/zixun/xiangqing/474431.html)
- **有 API 也不代表可以公开建库。** 以 CBDB 为例，其 API 按数据版本适用不同条款：单机版发布日期（含当日）之前且在其数据量范围内的数据适用 CC BY-NC-SA 4.0；之后或超出数据量的数据适用 CBDB 自订条款，**禁止演绎、再分发，以及作为公开网站、应用或 API 的数据来源**。[CBDB 授权说明](https://input.cbdb.fas.harvard.edu/cbdbapi/index.html)
- **“仅供研究”不能自动覆盖公开服务或全文发布。** 需要就每一项用途单独取得许可，或在引入时按最保守的用途裁剪材料。

## 4. EvidHist 的起步组合

起步阶段采用下列组合，专题材料再通过机构合作补充：

1. **中文维基文库中权利清楚的古籍原文**（逐部确认作品与版本状态）；
2. **Wikidata 结构化实体数据**（CC0，用于实体对齐和检索）；
3. **开放书目与版本元数据**（先建立“资料在哪里”的索引）；
4. **自行整理的证据标注**（标注结果与项目原创文档按项目许可发布）。

引入顺序上，先做权利状态最清楚的 1、2 两类，取得可核查的登记样例后，再扩展到其他来源。

## 5. 每份材料的登记字段

引入每份材料时至少保存以下字段，缺项按“未知”显式记录，不能用推测值填充：

| 字段 | 内容要求 |
| --- | --- |
| 来源 | 来源类型、机构或数据库名称、来源 ID 与入口地址 |
| 版本 | 作品版本、数据版本或发布批次；含权利状态判断所依据的版本 |
| 原文位置 | 卷次/篇目/页码或数据记录标识，能够回到原文核对 |
| 许可证及其快照 | 许可证名称与版本、官方条款链接、许可页面快照或其散列、获取日期 |
| 获取日期 | 实际取得材料的日期与时区 |
| 允许的用途 | 分别标注：存储、OCR/解析、检索、公开展示、再分发、模型训练 |

这些字段与[架构文档第 8 章](architecture-analysis-2026-10-09.md#8-爬虫与史料采集)的来源适配器输出（来源 ID、原始与最终地址、获取时间、响应元数据、内容散列、原始对象位置、许可信息、解析器版本）对应；本文补充的是**许可证快照与逐用途授权**两项要求。许可页面会被修改，只记录链接不足以复原引入时的授权状态。

## 6. 项目自身许可与第三方许可的关系

- **项目许可不能替代第三方材料的许可。** 代码、配置、脚本、测试和代码示例采用 [MIT](../LICENSE)，原创文字文档采用 [CC BY-NC-SA 4.0](../LICENSE-DOCS.md)；第三方史料、论文、数据集仍按各自条件使用，并在材料登记中独立标识，见 [README 第 3 节](../README.md#3-许可证)。
- **引入 CC BY-SA 内容时，不能直接改以 CC BY-NC-SA 发布。** ShareAlike 要求在演绎作品中继续使用相同许可或 CC 认定的兼容许可，而 CC BY-NC-SA 不是 BY-SA 4.0 的兼容许可。[CC BY-SA 4.0 条款](https://creativecommons.org/licenses/by-sa/4.0/deed.zh-hans)、[CC 官方 FAQ：组合不同 CC 许可材料](https://creativecommons.org/faq/#can-i-combine-material-under-different-creative-commons-licenses-in-my-work)
- **对本项目的直接后果**：若某份史料的注释、译文或校对成果来自 CC BY-SA 来源，则包含该部分的成果需要按 BY-SA 提供，或改为不引入该部分。此类材料应在引入前决定，而不是在发布时补救。
