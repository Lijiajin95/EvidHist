# EvidHist

**历史领域信息可靠性验证引擎**

EvidHist 是一个面向中文历史史料使用者的**个人产品项目**，计划在 GitHub 开源代码，持续提供可使用、可核查、可维护的史料整理与可靠性验证能力。

- **状态**：后端服务与首个前端界面（引文定位）可本地运行；工程检查门槛已按交接清单验收，核心产品能力处于设计阶段
- **更新日期**：2026-10-09
- **语言与史料范围**：中文，以文言文及近现代中文文献为主
- **许可证**：代码 MIT；原创文档 CC BY-NC-SA 4.0

本文记录项目目标与功能需求，所述研究能力均为设计目标。当前已提供可运行的后端服务、引用定位规则、首个真实前端界面（引文定位）及前后端完整的本地检查入口；史料库、业务持久化、完整历史研究能力及真实模型评测仍待实现。运行与验证方法见[开发与检查说明](docs/development.md)。

当前设计与代码验收分别记录。Python 升级、提交约束及前端工程的落实事项见[代码 Agent 交接清单](docs/coding-agent-handoff-2026-10-09.md)。

## 1. 项目目标

EvidHist 面向历史研究，帮助研究者从多源史料中检索、提取、整合与验证信息，进行多源互证、冲突检测、独立验证和可追溯推理。

项目关注历史论断与证据之间的关系：论断来自哪里，原文是否支持论断，不同记载是否相互独立、是否存在冲突，哪些内容属于推断，以及现有证据能够支持多大程度的确定性。

核心目标包括：

- **事实性论断有来源绑定**：每个事实性论断必须关联可核查的史料、版本与原文位置，使研究者能够回到原文检查。
- **推断明确标注，争议完整保留**：区分史料直接记载与分析所得推断，保留分歧观点及其证据。史料中有明确记载，并不自动意味着该记载已被证实为历史事实。
- **冲突显式呈现**：存在相互冲突的观点时，至少并列呈现两种实际存在的观点、各自来源及冲突内容，说明支持依据与未决问题。
- **表达不确定性与证据强度**：区分事实、推断、争议、未知，对证据强度分级并保留分级依据。
- **支持完整分析流程**：覆盖史料检索、信息提取、多源整合与可靠性验证，使分析结果能够追溯到原始材料和推理依据。

**史料基础设施是 EvidHist 的必要组成部分。** 史料必须经过采集、结构化、存储与索引，才能被检索、比对和验证。史料库建设为多源互证、冲突检测、独立验证与可追溯推理提供必要的材料基础。

项目聚焦**中文历史史料，以文言文及近现代中文文献为主**，文本处理以已有可用文本为基础。

## 2. 核心功能

以下按功能领域组织，不表示实现优先级或执行顺序。

### 史料基础设施

- **史料采集与整理**：从公开且依法可用的来源获取正史、学术论文、档案、碑铭、气候数据、经济史研究等材料，保留出处与使用条件。
- **史料结构化**：将非结构化文本转化为可计算数据，标注来源、年代、作者、版本，保留与原文的对应关系。
- **史料存储与索引**：支持按时间、地理、人物、事件、主题等维度检索史料。
- **知识图谱构建**：对实体、事件与关系进行结构化表示，支持查询及证据关联。
- **实体与关系管理**：对人物、地点、机构、事件进行消歧、对齐与关联，区分同名实体及不同称谓。
- **版本与来源追踪**：记录史料版本流传、引用关系与来源可靠性元数据，识别转引及共同出处。
- **多源异构数据整合**：整合编年层、地理层、制度层、传记层、图像层等材料，保留各类数据的来源与关联。
- **实体标注与关系抽取**：从史料文本中标注实体、提取关系，并关联对应原文。
- **史料摘要与主题分类**：提炼史料内容、组织主题，保留摘要与原文之间的对应关系。

### 历史研究与分析

- **多源互证**：比较不同来源对同一人物、事件或论断的记载，识别相互支持的证据及其来源独立性。同源转引须保留共同出处，避免重复计为独立证据。
- **冲突检测**：发现不同来源在时间、人物、事件过程及解释等方面的分歧，并列呈现冲突内容与来源。
- **独立验证**：回到可核查史料，检查论断、引用及推理依据；说明所用证据与原论断的来源关系，标注独立性不足或无法完成验证的情况。
- **不确定性标注**：区分事实、推断、争议、未知，说明不确定性来自史料缺失、记载模糊、来源冲突还是推理不足。
- **可追溯生成**：生成内容保留论断、证据与推断之间的对应关系，使研究者能够核查结论依据。
- **机制解释与因果推理**：依据史料分析事件之间的作用机制，区分时间先后、相关关系与因果推断，标注解释的证据与不确定性。
- **时间线重建**：整合分散记载，重建人物活动及事件顺序，保留时间推断依据、模糊范围与冲突记载。
- **知识图谱查询与推理**：查询实体、事件及关系，基于有来源支持的关系进行推理，并保留推断依据。
- **矛盾检测与冲突标注**：标注同一材料内部及跨材料之间的矛盾，保留相关原文与论断。
- **证据强度分级**：结合来源可靠性、独立性及对论断的直接支撑程度，对证据强度分级并说明依据。
- **交互式时间线**：支持沿时间线查看事件、人物、来源及争议，回查对应史料。
- **AB 路径分析**：分析实体 A 与实体 B 之间的关系路径，展示路径中的实体、关系与来源依据。路径展示须区分有记载的关系和推断关系，因果解释需要另有证据支持。

### 知识图谱与可视化

- **关系图谱动态呈现**：动态展示人物、地点、机构、事件之间的关联，并呈现关系所依赖的证据。
- **时空地图**：结合事件时间与地点，展示历史活动的时空分布及变化。
- **交互式时间线**：展示不同来源支持的事件顺序、时间范围与冲突，支持查看对应证据。
- **地理信息可视化**：展示历史地点与空间关系，保留地理判断的来源及不确定性。

### 可靠性验证核心

- **论断提取**：从史料与生成内容中提取可验证的事实性论断，并区分推断及观点。
- **来源绑定**：将论断关联到具体来源、版本与原文位置，检查证据是否确实支持论断。
- **冲突检测**：识别同一论断的不同记载及解释，保留冲突双方或多方的证据。
- **独立验证**：核查来源真实性、原文支撑关系及证据独立性，记录验证结果与无法核查的部分。
- **不确定性标注**：为论断标注事实、推断、争议或未知状态，并说明依据。标注须分别说明史料记载情况与历史事实的核查情况。
- **错误样例回流（Badcase）**：记录错误样例、相关论断、原始材料与验证结果，用于改进史料整理、分析及评测。
- **引用溯源与幻觉检测**：检查引用是否存在、定位是否正确、原文是否支持论断，识别虚构来源、错误引用及与证据不符的生成内容。证据不足或暂时无法核查的内容保留未知状态。

评测采用以下指标：

| 指标 | 评测含义 |
| --- | --- |
| 引用准确率 | 来源可核查、定位正确且支持对应论断的引用数，占全部被评测引用数的比例 |
| 引用错误率 | 已确认来源不存在、定位错误或不能支持对应论断的引用数，占全部被评测引用数的比例 |
| 冲突检测率 | 正确识别的真实冲突数，占人工标注集中全部真实冲突数的比例 |
| 不确定性标注准确率 | 与人工标注判定一致的事实、推断、争议、未知标签数，占全部被评测标签数的比例 |
| 幻觉率 | 已确认虚构或与可核查证据不符的事实性论断数，占全部被评测事实性论断数的比例 |

评测须明确材料与版本、评测对象、人工标注依据、各指标的分子与分母，并保留无法核查的数量及原因。未核查内容不能直接计为正确或错误，因此引用准确率与引用错误率不必相加为 100%；分母为零时，指标记为不可计算。材料是否被忠实引用、论断是否得到支撑与历史解释是否合理，须分别核查。

## 5. 相关项目与参考

以下项目、论文与数据集为设计提供参考。所列功能、数据规模与公开成绩属于对应项目；资料核验日期为 **2026-10-08**。

### 历史 Agent 与评测

- **[HistAgent](https://github.com/CharlesQ9/HistAgent)**：面向历史问答的研究项目，集成档案检索、图像理解等工具。其官方仓库报告，基于 GPT-4o 的 HistAgent 在 HistBench 上取得 **27.54% pass@1**。
- **[AI Historian](https://github.com/YiFengLu1999/AI-Historian)**：从碎片化文本证据中重建历史时间线，支持 DeepSeek 等模型配置，可参考其事件整理与时间依据处理方式。
- **[Chronos](https://github.com/ai-historian/chronos)**：与历史研究者协作，从原始史料提取结构化数据，可参考其证据关联与材料整理方式。
- **[清史智能体](https://se-office.ruc.edu.cn/xwdt/994fc1bb9f764a5f9b8e291cdf8a0372.htm)**：由中国人民大学清史研究所与国家治理大数据和人工智能创新平台合作研发；官方介绍涉及多源互证、可追溯生成与机制解释。
- **[HistBench](https://arxiv.org/abs/2505.20246)**：包含 **414 道历史研究问题，涉及 29 种语言**，可参考其历史研究任务组织与评测方法。
- **[ProHist-Bench](https://arxiv.org/abs/2604.24690)**：以中国科举史为中心的专业历史研究评测集，论文报告 **400 道题、10,891 条评分细则（rubrics）**。
- **[HiST-LLM](https://zenodo.org/records/14671248)**：基于 Seshat 历史数据库构建的全球历史知识评测基准，可参考其历史知识组织与评测方法。
- **[hist-rag-bench](https://huggingface.co/datasets/ai-forever/hist-rag-bench-public-questions)**：公开检索问答数据，当前公开问题样例包含俄语新闻等内容。在本项目中仅作为评测设计参考，中文历史研究适用性需要根据实际材料核查。
- **[CHisIEC](https://github.com/tangxuemei1995/CHisIEC)**：中国古代历史信息抽取语料库，提供实体识别与关系抽取资源，可参考其标注方式与任务设计。

### 知识库与可视化

- **[史记知识库](https://github.com/baojie/shiji-kb)**：将《史记》组织为可交互知识图谱。项目 README 所列 **2026-05-14 数据快照**包含 **14,065 个实体、3,198 个历史事件、7,637 条事件关系**。
- **[全知识平台](https://mp.allhistory.com/)**：提供关系图谱、AB 路径和时空地图等功能，可参考其实体关系与路径展示方式。
- **[nodegoat](https://nodegoat.net/documentation)**：面向人文研究的数据管理与可视化环境，支持来源记录、编年、地理及关系可视化。
- **[heuritab](https://github.com/j-sheik/heuritab)**：面向历史研究者的 AI 驱动 JSON 语料管理器，结合向量检索与批量模型查询，支持语料检索和信息提取。

### 协议与框架资料

- **[AG-UI](https://docs.ag-ui.com/spec/1.0/basic/patterns/interrupt-resume)**：Agent-User Interaction Protocol，提供交互与暂停恢复的参考资料。
- **[DeepSeek Harness（dsh）](https://github.com/deepseek-ai/deepseek-harness)**：DeepSeek 发布的 Agent 运行时框架，采用 MIT 许可证。
- **[MCP](https://modelcontextprotocol.io/specification/2026-07-28)**：Model Context Protocol，提供模型与外部工具、数据连接的规范资料。
- **[LangGraph](https://github.com/langchain-ai/langgraph)**：用于有状态工作流与 Agent 的框架，可参考其持久执行与人工介入资料。
